# Norrsken – WooCommerce to Shopify Migration
**Project Type:** Professional Platform Migration
**Stack:** Shopify (Liquid), Python/Automation

## Project Overview
Technical lead for migrating legacy WooCommerce stores to Shopify. The focus was on preserving data integrity and modernizing the tech stack.

## Key Technical Achievements
* **ETL (Extract, Transform, Load):** Developed workflows to extract product, customer, and order history from WordPress/WooCommerce and map them to Shopify’s data structure.
* **Theme Modernization:** Rebuilt the store identity in Liquid, improving mobile performance and checkout conversion rates compared to the previous legacy setups.
* **SEO Continuity:** Managed URL redirects and metadata migration to ensure no loss in search engine ranking during the transition.
